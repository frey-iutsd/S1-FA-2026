## Séance 2 : vos fichiers

Dans **[word2/fichiers/](word2/fichiers/)**, prenez les deux fichiers qui portent **votre prénom et l'initiale de votre nom** (par exemple `Lea_M-devis.txt` et `Lea_M-rapport.txt`). Si on vous a attribué un fichier de réserve (`R01`, `R02`…), prenez celui-là.

Ouvrez le fichier, cliquez sur **Raw**, puis **Ctrl+A** et **Ctrl+C** : la fiche explique la suite.
